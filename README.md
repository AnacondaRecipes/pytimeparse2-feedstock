Installing pytimeparse2
==================

Installing `pytimeparse2` from the main channel can be achieved by:

```
conda install pytimeparse2
```

It is possible to list all of the versions of `pytimeparse2` available on your platform with `conda`:

```
conda search pytimeparse2
```
